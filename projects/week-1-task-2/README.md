# Неделя 1, задание 2: управление форматом ответа

CLI-приложение отправляет DeepSeek API один и тот же запрос дважды и сравнивает ответы:

1. без ограничений формата и длины;
2. с заданным форматом, лимитом длины и условием завершения.

## Требования

- Python 3.11+
- API-ключ DeepSeek

Сторонние библиотеки не требуются.

## Настройка

Создайте `.env` в корне репозитория:

```env
DEEPSEEK_API_KEY=your_api_key
```

Файл `.env` исключён из Git.

## Запуск

Из корня репозитория:

```powershell
python projects/week-1-task-2/main.py
```

Сначала программа запросит данные для вызова без ограничений и выведет ответ. Затем попросит повторить те же данные для вызова с контролем:

```text
WITHOUT CONTROLS
Name: Astin Ray, VAVA - TAKIPARIO
Description: agressive phonk with female vocal

RESPONSE (... words)
...

WITH CONTROLS
Name: Astin Ray, VAVA - TAKIPARIO
Description: agressive phonk with female vocal
```

Если два ввода различаются, программа остановится: для корректного сравнения запрос должен быть одинаковым.

## Уровни контроля

Оба API-вызова получают одинаковый `user_prompt` с названием и описанием трека. Пользователь вводит его перед каждым вызовом.

Первый вызов содержит только общую инструкцию написать питч.

Второй вызов задаёт:

- формат `PITCH: <one paragraph>`;
- длину не более 45 слов;
- `max_tokens=100` как технический лимит;
- завершение маркером `<END>`;
- `stop=["<END>"]`, поэтому маркер останавливает генерацию и не входит в ответ.

Программа выводит оба ответа и количество слов для сравнения.
