# Неделя 1, задание 3: разные способы рассуждения

CLI-приложение решает одну аналитическую задачу через DeepSeek API четырьмя способами и автоматически сравнивает точность ответов.

## Задача

Сравнить две рекламные кампании интернет-магазина по четырём метрикам:

- конверсия;
- средний чек;
- ROAS;
- прибыль после рекламных расходов и себестоимости.

После расчётов модель должна рекомендовать кампанию при приоритете прибыли и ROAS и отметить компромисс между метриками.

## Эталон

```text
Кампания A: конверсия 3%, средний чек $300, ROAS 6.0, прибыль $36 000
Кампания B: конверсия 4%, средний чек $280, ROAS 4.48, прибыль $24 800
Рекомендация: кампания A для максимальной прибыли и ROAS
Компромисс: у кампании B выше конверсия
```

Эталон используется только локальной проверкой и не передаётся модели.

## Способы решения

1. Прямой ответ без дополнительных инструкций.
2. Тот же запрос с инструкцией `Решай пошагово`.
3. Модель сначала составляет улучшенный промпт на русском языке, затем новый API-вызов решает задачу по нему.
4. Системный промпт создаёт консилиум из аналитика данных, финансового специалиста и критика. После независимых проверок модель формирует консенсус.

Условие задачи, инструкции и ответы модели — на русском языке. Имена переменных и служебные элементы Python — на английском.

Все итоговые решения используют одну модель и одинаковые параметры генерации. Дополнительный API-вызов третьего способа применяется только для создания prompt.

## Сравнение

Программа проверяет девять критериев: восемь вычисленных значений и рекомендацию Campaign A. Для каждого способа выводятся точность и количество слов.

```text
Прямой ответ: точность=.../9, слов=...
Пошаговое решение: точность=.../9, слов=...
Сгенерированный промпт: точность=.../9, слов=...
Группа экспертов: точность=.../9, слов=...
Ответы отличаются: ДА/НЕТ
Самые точные: ...
```

Если несколько способов набрали одинаковый максимальный балл, результат отмечается как равный по точности.

## Результат проверочного запуска

```text
Прямой ответ: точность=9/9, слов=392
Пошаговое решение: точность=9/9, слов=471
Сгенерированный промпт: точность=9/9, слов=104
Группа экспертов: точность=9/9, слов=535
Ответы отличаются: ДА
Самые точные: все четыре способа (9/9)
```

Все способы дали точный результат. Generated prompt сформировал самый короткий ответ, экспертная группа — самый подробный анализ и проверку дополнительных бизнес-метрик.
