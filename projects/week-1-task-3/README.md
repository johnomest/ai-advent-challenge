# Неделя 1, задание 3: разные способы рассуждения

CLI-приложение решает одну алгоритмическую задачу через DeepSeek API четырьмя способами и автоматически сравнивает точность ответов.

## Задача

Найти кратчайший путь из `A` в `F` во взвешенном неориентированном графе.

Эталонный ответ заранее вычислен и используется только локальной проверкой:

```text
A-C-B-D-E-F, стоимость 13
```

Модель эталон не получает.

## Способы решения

1. Прямой ответ без дополнительных инструкций.
2. Тот же запрос с инструкцией `Solve step by step`.
3. Модель сначала составляет улучшенный prompt, затем новый API-вызов решает задачу по нему.
4. Системный prompt создаёт консилиум из аналитика, инженера и критика; каждый предлагает или проверяет решение, затем формируется консенсус.

Все итоговые решения используют одну модель и одинаковые параметры генерации. Дополнительный API-вызов третьего способа применяется только для создания prompt.

## Сравнение

Программа для каждого решения выводит:

- совпал ли путь с эталоном;
- совпала ли стоимость;
- количество слов;
- отличаются ли ответы;
- какие способы дали точный результат.

Если несколько способов нашли правильный путь и стоимость, результат честно отмечается как равный по точности.

## Результат проверочного запуска

```text
Direct: path=PASS, cost=PASS
Step by step: path=PASS, cost=PASS
Generated prompt: path=PASS, cost=FAIL
Expert panel: path=PASS, cost=PASS
Answers differ: YES
Most accurate: Direct, Step by step, Expert panel
```

Третий способ нашёл правильный путь, но указал стоимость `15` вместо `13`. Это показывает, что улучшенный prompt не гарантирует правильное решение, а результат нужно проверять по объективному критерию.

## Требования

- Python 3.11+
- API-ключ DeepSeek

Сторонние библиотеки не требуются.

## Настройка

Создайте `.env` в корне репозитория:

```env
DEEPSEEK_API_KEY=your_api_key
```

```powershell
python projects/week-1-task-3/main.py
```
