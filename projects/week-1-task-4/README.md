# Неделя 1, задание 4: температура

CLI-приложение прогоняет три вымышленных трека через генератор музыкальных питчей с тремя значениями `temperature` и выводит ответы подряд в консоль. Ручной ввод не требуется.

## Значения температуры

- `0` — максимально предсказуемый ответ;
- `0.7` — баланс точности и вариативности;
- `1.2` — более свободная и креативная генерация.

Для каждого трека меняется только `temperature`. Модель, системный промпт и данные трека остаются одинаковыми, поэтому ответы можно корректно сравнивать.

## Результаты сравнения

Проверочный запуск показал следующие различия:

- `temperature = 0` — наиболее сдержанные, предсказуемые и близкие к исходному описанию питчи. Подходит для шаблонных описаний, извлечения фактов и задач, где важнее точность.
- `temperature = 0.7` — формулировки стали разнообразнее и образнее, но ответы сохранили связность. Подходит для маркетинговых текстов и обычной творческой генерации.
- `temperature = 1.2` — модель использовала более свободные формулировки, но повысился риск выдуманных деталей и ошибок. В одном ответе появилось несуществующее слово `фасека`. Подходит для поиска идей и черновиков, которые затем проверяет человек.

Высокая температура не гарантирует, что каждый ответ будет длиннее или заметно креативнее. Она увеличивает случайность выбора слов, поэтому эффект зависит от запроса и конкретного запуска.

Итог: низкая температура лучше сохраняет точность, средняя даёт баланс точности и креативности, высокая повышает разнообразие вместе с риском галлюцинаций.

## Требования

- Python 3.11+
- API-ключ DeepSeek в `.env` в корне репозитория

Сторонние библиотеки не требуются.

## Запуск

```powershell
python projects/week-1-task-4/main.py
```

В коде заданы три примера:

```text
Mira Vale - Neon Static
мрачный синтвейв с женским шёпотом и напряжённым настроением ночной поездки

Northbound - Rusted Halo
кинематографичный альтернативный рок с хриплым мужским вокалом и решительным настроением

Luma, Davi - Mango Rush
яркий бразильский фанк-поп с игривым дуэтным вокалом и настроением летней вечеринки
```

Для каждого трека программа выведет три блока:

```text
============ ТЕМПЕРАТУРА 0 ============
...

============ ТЕМПЕРАТУРА 0.7 ============
...

============ ТЕМПЕРАТУРА 1.2 ============
...
```
