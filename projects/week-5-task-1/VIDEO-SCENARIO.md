# День 21 — сценарий записи

## Текущая сдача — PDF How to Get Hired, 3–5 минут

1. Показать PDF: 38 страниц. Сказать: «37 страниц с текстовым слоем, 8291 слово; обложка без OCR не индексируется». Страницы — физические номера PDF, не печатная нумерация книги.
2. Открыть `index_pdf.py`: извлечение `pdfplumber`, чтение двух колонок последовательно, сохранение отдельных `pages/page-NNN.md`. Исходный PDF не меняется.
3. Открыть `main.py`: `fixed_chunks`, `structured_chunks`, `word_windows`.
   - Fixed-size: окна 180 слов с overlap 30, короткое последнее окно допустимо.
   - Structural: структура по файлам страниц. Короткие страницы целиком, длинные разбиваются с тем же лимитом. Это не распознавание смысловых заголовков книги.
4. Запустить из корня репозитория:

   ```powershell
   .\.venv\Scripts\python.exe projects/week-5-task-1/index_pdf.py "D:\Work\Projects\ai-advent-challenge\projects\week-5-task-1\data\How to Get Hired.pdf" --output-dir projects/week-5-task-1/data/how-to-get-hired-video
   ```

   `pdfplumber` установлен в локальном `.venv`; нужен работающий Ollama. Использовать новый каталог вывода: уже извлечённые страницы не перезаписываются.

5. Показать `Saved and validated` обоих индексов и `COMPARISON`:
   - fixed: 79 чанков, средний размер 122.7 слова;
   - structure: 63 чанка, средний размер 143.8 слова;
   - оба: размерность 768, максимум 180 слов.
     Числа брать из показанного запуска. Длинное ожидание можно вырезать с обозначением монтажа.
6. Открыть по одному чанку каждого JSON: `source`, `title`, `section`, `chunk_id`, `strategy`, `page`, `text`, `embedding`. Показать размерность, не выводить все 768 чисел.
7. Открыть `extraction-report.json`: объём корпуса, пропущенная обложка, SHA-256 и сравнение размеров. На короткой странице показать разницу: structural оставляет её целиком, fixed-size дробит окнами.
8. Запустить `.\.venv\Scripts\python.exe -m unittest discover projects/week-5-task-1 -v`: шесть тестов.
9. Озвучить: «Два локальных индекса готовы. Структурный вариант даёт меньше, более крупных чанков и сохраняет короткие страницы целиком. У каждого фрагмента есть источник и номер страницы. Качество поиска этим сравнением пока не оценивалось».

   Фундаментальные навыки специализации, одна-две сильные области, фотореализм и оригинальность в учебных работах.

5. **Что может испортить шансы кандидата на собеседовании в Framestore?**  
   Недостаточная командность, слабая коммуникация и неспособность замечать, что улучшить в собственной работе.
