# День 22 — первый RAG-запрос

Корпус: PDF **How to Get Hired**, structural-индекс Дня 21. Код Дня 23 не используется.

## Что изучаем

Вопрос → локальный embedding → cosine similarity → top-K чанков →
вопрос вместе с найденным контекстом → DeepSeek → ответ с источниками.
Тот же вопрос отдельно задаётся DeepSeek без фрагментов книги.
Здесь нет query rewrite, threshold или reranker: это следующий этап.

## Запуск

Из корня репозитория, в установленном `.venv`:

```powershell
python projects/week-5-task-2/main.py --with-answers
```

Без активированного окружения использовать `.\.venv\Scripts\python.exe` вместо `python`.
Ключ DeepSeek читается из корневого `.env` или окружения, без вывода в терминал.
Ollama с `embeddinggemma` должен работать. Индекс по умолчанию:
`projects/week-5-task-1/data/how-to-get-hired-video/index-structure.json`.
Другой индекс передаётся через `--index`.

```powershell
python projects/week-5-task-2/main.py --with-answers --question "Какие соцсети Framestore проверяет перед наймом?" --top-k 5
```

Вывод: найденные фрагменты со score, страницей и chunk_id; `WITHOUT RAG`; `WITH RAG`.
Ожидаемый ответ нужно сверять с источником, а не только со score.

## Десять контрольных вопросов

`control_questions.json` содержит десять вопросов, ожидания, исходный PDF,
физические страницы и контрольные термины. Прогон обоих режимов:

```powershell
python projects/week-5-task-2/main.py --evaluate --with-answers --output projects/week-5-task-2/data/evaluation-answers.json
```

Это **20 вызовов DeepSeek**, два на вопрос. Выбранные фрагменты PDF отправляются
в облачную модель для RAG-ответа; embeddings остаются локальными. Пользователь
разрешил передачу выбранных фрагментов 2026-10-05. Без `--with-answers`
программа проверяет только локальный поиск и не обращается в облако.

`page_hit` показывает попадание ожидаемой страницы, `evidence_hit` дополнительно
проверяет контрольные слова внутри одного найденного чанка. Эти метрики не
оценивают правильность ответа модели. Ответы в обоих режимах сравниваются
вручную по полноте, сохранению условий, отсутствию выдумок и правильности источников.

Результаты и фрагменты сохраняются в `data/`, исключённой из Git. Индекс
не меняется. Книга и её извлечённый текст не публикуются вместе с кодом.

## Проверка

```powershell
python -m unittest discover projects/week-5-task-2 -v
```

Шесть тестов: similarity, top-K, различие попадания страницы и доказательства,
отсутствие контекста в baseline, наличие метаданных в RAG-промпте и пустой контекст.

## Реальный прогон

[Сравнение десяти вопросов и ограничения](RESULTS.md): ожидаемая страница и
контрольные слова найдены в 9/10 случаев. Это не доля правильных ответов.
Ручная проверка выявила пропущенный источник для IV и смешение условий
Framestore / Ranger & Fox в одном ответе. Провалы сохранены для честного
baseline перед следующим заданием.
