# День 22 — сценарий видео, 4–6 минут

1. «День 22: сравниваю один и тот же вопрос без RAG и с контекстом из книги How to Get Hired».
2. Показать structural-индекс Дня 21 и `control_questions.json`: десять вопросов,
   поля `expected`, `source`, `pages`. Это физические страницы PDF.
3. Показать `retrieve` и `ask`: поиск локальный, затем вопрос вместе с top-5
   фрагментами передаётся DeepSeek. В baseline фрагменты отсутствуют.
4. Запустить:

   ```powershell
   python projects/week-5-task-2/main.py --with-answers --question "Нужен ли диплом, чтобы устроиться в Framestore?"
   ```

5. Сравнить `WITHOUT RAG` и `WITH RAG`. Ожидание: студия оценивает reel, но
   в книге есть отдельная оговорка о дипломе и работе за рубежом. Проверить,
   нашёлся ли именно этот фрагмент; общий совет без исключения — неполный ответ.
6. Показать источник, физическую страницу и chunk_id RAG-ответа. Сверить смысл
   по короткому фрагменту страницы 13, не публиковать всю книгу.
7. Повторить на вопросе о LinkedIn. Проверить студийное условие: LinkedIn всегда,
   другие соцсети обычно только при наличии ссылки из профиля.
8. Показать прогон набора:

   ```powershell
   python projects/week-5-task-2/main.py --evaluate --with-answers --output projects/week-5-task-2/data/evaluation-answers.json
   ```

   Ожидание модели можно ускорить монтажом. Показать все десять вопросов,
   сохранённые ответы и фактическое сравнение; провалы не скрывать.
9. Объяснить: `page_hit` и `evidence_hit` проверяют retrieval, не качество
   генерации. Качество сравнивается по ожидаемому смыслу, оговоркам и источникам.
10. «RAG добавляет конкретный контекст книги. Без него модель даёт общие советы
    или признаёт незнание; найденная страница сама по себе ещё не гарантирует
    точный ответ». Подтвердить вывод своими реальными результатами.

## Чеклист

- [ ] Один вопрос показан в двух режимах одной модели.
- [ ] Есть десять контрольных вопросов с ожиданиями и источниками.
- [ ] Видны score, page, chunk_id найденных фрагментов.
- [ ] Смысл ответов сверён вручную, retrieval не выдан за оценку генерации.
- [ ] Нет ключей, `.env`, чужих данных или публикации полной книги.

`--with-answers` передаёт выбранные фрагменты в DeepSeek; без флага поиск полностью локальный.
