# День 23 — сценарий видео

Имя: `usage-video-w5-t3.mp4`. Терминал в корне репозитория, `.venv` активировано.

## 1. Объяснить цель

«Берём тот же PDF и вопросы Дня 22. Сравниваем обычный RAG и RAG с переписыванием
запроса, порогом, фильтрацией студии и локальным реранкингом».

## 2. Показать проблемный вопрос

```powershell
python projects/week-5-task-3/main.py --with-answers
```

Показать `QUESTION`, `REWRITTEN QUERY`, `SETTINGS`, `FILTERING`.
Объяснить: поиск по 20 кандидатов для исходного и английского запросов;
порог 0.40; в ответ попадает максимум пять чанков.

Сверить два ответа на вопрос об образовании IV. Ожидание: студия не отсекает по
образованию, ценит сами работы. Источник — физическая страница PDF 24.
Показать, появился ли этот источник в improved и отсутствует ли в baseline.
Если новая генерация отличается, показываем фактический результат.

## 3. Проверить границы источников

```powershell
python projects/week-5-task-3/main.py --question "Какие работы и навыки Framestore ищет при просмотре портфолио?" --with-answers
```

Показать `studio_filter: FRAMESTORE`. В improved не должно быть Ranger & Fox.
Проверить, что ответ про photo-real / originality подтверждается Framestore,
а чужие требования не приписаны этой студии.

## 4. Показать отказ при пустом контексте

Сначала вопрос вне базы при рабочем пороге:

```powershell
python projects/week-5-task-3/main.py --question "Как приготовить борщ с говядиной?" --with-answers
```

Показать, что baseline всё равно выбирает пять чанков, а improved отсекает
нерелевантные совпадения. В проверенном поисковом прогоне итог — ноль чанков;
при новом запуске сверяем фактические score и результат.

Затем жёсткий порог на вопросе внутри базы:

```powershell
python projects/week-5-task-3/main.py --question "Как студия IV относится к художественному образованию кандидата?" --threshold 1 --with-answers
```

Для этого вопроса порог 1 должен убрать все результаты. Показать `final_chunks: 0`
и сообщение о недостатке контекста вместо выдуманного improved-ответа.
Это демонстрация механизма, не рекомендуемая рабочая настройка.

## 5. Показать полный контрольный набор

```powershell
python projects/week-5-task-3/main.py --evaluate --with-answers --output projects/week-5-task-3/data/evaluation-answers.json
```

Дождаться `SUMMARY` и `Saved`. Прогон платный: до 30 облачных запросов.
Для короткого видео можно показать сохранённый результат предыдущего прогона,
явно сказав, что он записан заранее:

```powershell
$report = Get-Content -Raw -Encoding UTF8 projects/week-5-task-3/data/evaluation-answers.json | ConvertFrom-Json
$report.summary | ConvertTo-Json -Depth 4
```

Итог: попадание источников не равно точности ответа. Сверяем содержание,
условия и принадлежность цитируемых фрагментов вручную.
