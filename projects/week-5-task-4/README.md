# День 24 — цитаты, источники и отказ от галлюцинаций

Задание реализовано в production-проекте `goost-tools`: Telegram RAG-чат принимает ответ только тогда, когда каждая использованная цитата дословно присутствует в найденном чанке.

## Что изучаем

- grounded generation;
- проверку ответа на уровне приложения;
- связь `chunk_id → source → section → exact quote`;
- безопасный отказ при слабом контексте или непроверяемой цитате.

## Реализация

Основные файлы production-проекта:

- `services/telegram/bot_app/knowledge.py` — индекс и retrieval;
- `services/telegram/bot_app/deepseek.py` — формат ответа, проверка точных цитат, источники и отказ;
- `tests/test_deepseek.py` — успешный grounded-ответ и отклонение выдуманной цитаты.

В этой папке лежит публичный синтетический набор из 10 проверок. Он не содержит внутреннюю базу, реальные ответы, embeddings или секреты.

## Запуск проверки

```powershell
python projects/week-5-task-4/evaluate.py
python -m unittest discover projects/week-5-task-4 -v
```

## Сценарий видео

1. Показать структуру ответа: текст, источники, точные цитаты.
2. Запустить 10 синтетических проверок.
3. Показать успешную проверку дословной цитаты.
4. Изменить цитату на отсутствующую в чанке и показать отказ.
5. Объяснить: модель предлагает доказательство, но доверяет ему только приложение.

## Вывод

Список источников сам по себе не защищает от галлюцинаций. Проверка точной цитаты связывает утверждение с конкретным фрагментом, а fail-closed отказ не позволяет показать пользователю непроверяемый ответ.
