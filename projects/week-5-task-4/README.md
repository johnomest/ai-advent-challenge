# День 24 — цитаты, источники и «не знаю»

## Цель

Проверяемый RAG-ответ: **утверждение → точная цитата → источник**.
Берём PDF-индекс Дня 21, контрольные вопросы Дня 22 и improved-поиск Дня 23.
Предыдущие дни не изменяются. Новые зависимости не нужны.

## Реализация

1. Query rewrite, поиск, threshold 0.40, фильтр студии и heuristic reranker из Дня 23.
2. DeepSeek возвращает JSON: `status`, `claims`, `clarification`.
3. Каждое утверждение содержит текст ответа и 1–3 пары `chunk_id + quote`.
4. Локальный валидатор проверяет схему, наличие цитат, принадлежность chunk_id
   найденному контексту, точное вхождение цитаты в текст чанка. Нормализуются
   только пробелы и переводы строк; перевод, перефразирование и многоточия запрещены.
5. `source`, `section`, `chunk_id`, `page` берутся из индекса, не из фантазии модели.
6. Консоль и JSON содержат ответ, список источников, цитаты с номером утверждения.

Порог проверяется и непосредственно перед генерацией. При пустом/слабом контексте
ответ локальный: **«Не знаю» + просьба уточнить вопрос**, без генерации ответа.
Модель также может отказаться, если прямых доказательств в найденных чанках нет.
Невалидный JSON или неподтверждённая цитата отклоняет весь ответ. Разрешена одна
повторная генерация с обратной связью валидатора; если она тоже невалидна,
показывается отказ. Попытки и ошибки сохранены в JSON. Неподтверждённый
текст не показывается. `reason` различает `weak_context`, `no_direct_evidence` и
`invalid_evidence`. Сетевые ошибки показываются как ошибки, не как «не знаю».

При отказе источники и цитаты пусты намеренно: нельзя выдавать нерелевантные
фрагменты за подтверждение. Для содержательного ответа они обязательны.

## Запуск

Из корня репозитория с активированным `.venv`:

```powershell
python projects/week-5-task-4/main.py --with-answers
```

По умолчанию вопрос о дипломе Framestore. Другой вопрос:

```powershell
python projects/week-5-task-4/main.py --question "Нужен ли студии IV отдельный resume или достаточно portfolio?" --with-answers
```

Без активированного окружения: `.\.venv\Scripts\python.exe` вместо `python`.
Нужны Ollama с `embeddinggemma`, индекс
`projects/week-5-task-1/data/how-to-get-hired-video/index-structure.json`
и `DEEPSEEK_API_KEY` в корневом `.env` или окружении.
Параметры: `--index`, `--model`, `--ollama-url`, `--threshold`, `--top-n`, `--top-k`.

## Десять контрольных вопросов

```powershell
python projects/week-5-task-4/main.py --evaluate --with-answers --output projects/week-5-task-4/data/evaluation-answers.json
```

Используется неизменённый `../week-5-task-2/control_questions.json`.
Обычно **20 вызовов DeepSeek**: десять rewrite + десять ответов, максимум 30
при повторной генерации каждого ответа. Выбранные фрагменты
PDF отправляются в облако согласно разрешению пользователя; embeddings локальные.
Без `--with-answers` запускается только retrieval с облачным rewrite — не ответы.
Индексы не перезаписываются. Результаты сохраняются после каждого вопроса,
`summary` появляется только после окончания полного набора. `data/` исключена из Git.

Автопроверки: `has_sources`, `has_quotes`, `quotes_valid`. Последняя означает
валидность структуры и дословность цитат, **не подтверждение смысла утверждений**.
`page_hit` и `evidence_hit` — метрики поиска. Смысл проверяем вручную:
для каждого утверждения прочитать связанную цитату, проверить студию, отрицание,
условия, исключения и отсутствие добавленных фактов. Результаты — в [results.md](results.md).

## Проверка отказа

```powershell
python projects/week-5-task-4/main.py --question "Как приготовить борщ с говядиной?" --with-answers
python projects/week-5-task-4/main.py --threshold 1 --with-answers
```

Во втором случае порог заведомо жёсткий: это проверка механизма, не рабочая настройка.
Rewrite остаётся облачным даже при локальном отказе от ответа.

## Ограничения

Дословность не доказывает, что цитата подтверждает утверждение: модель может
исказить перевод или условие. Поэтому не заявляем полное устранение галлюцинаций.
Порог 0.40 специфичен для корпуса/embedding-модели; similarity не вероятность истины.
Ограничения фильтра студий Дня 23 сохраняются. Уточнение запрашивается текстом;
этот CLI не ведёт многоходовой диалог.

```powershell
python -m unittest discover projects/week-5-task-4 -v
```
