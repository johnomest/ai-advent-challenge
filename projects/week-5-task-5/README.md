# День 25 — Telegram-чат с RAG и памятью задачи

Финальная сборка недели реализована как режим `/chat` production-бота `goost-tools`.

## Что изучаем

- объединение истории диалога, RAG и task state;
- изоляцию сессий по пользователю и Telegram topic;
- сохранение состояния в SQLite;
- сериализацию конкурентных сообщений;
- проверку длинных диалогов.

## Пользовательский сценарий

```text
/chat on
<обычные вопросы пользователя>
/chat status
/chat reset
/chat off
```

Сессия имеет ключ `(chat_id, topic_id, user_id)`. Бот отвечает только пользователю, который включил режим. Последние 30 реплик и память задачи переживают перезапуск. `/chat reset` очищает историю и память, но оставляет режим включённым; `/chat off` удаляет сессию полностью.

## Production-реализация

- `services/telegram/bot_app/handlers.py` — команды, allowlist, per-session lock и маршрутизация обычных сообщений;
- `services/telegram/bot_app/storage.py` — SQLite-сессии, история и task state;
- `services/telegram/bot_app/deepseek.py` — retrieval с историей, grounded-ответ, источники и обновление памяти.

## Проверка

Публичные сценарии содержат только структуру 2 × 12 ходов без внутренних ответов и цитат:

```powershell
python projects/week-5-task-5/evaluate.py
python -m unittest discover projects/week-5-task-5 -v
```

## Сценарий видео

1. В группе отправить `/chat on`.
2. Назвать цель, ограничение и термин.
3. Задать 10–12 последовательных вопросов обычными сообщениями.
4. На нескольких шагах показать источники и точные цитаты.
5. Выполнить `/chat status` и проверить сохранённые цель, ограничения и термины.
6. Попросить другого участника написать сообщение: бот не должен перехватить его без собственной `/chat on`.
7. Выполнить `/chat reset`, проверить пустую память и сохранённый `ON`.
8. Выполнить `/chat off` и убедиться, что обычные сообщения больше не обрабатываются.

## Вывод

RAG стал не отдельной командой, а управляемым диалоговым режимом. История даёт связность, task state удерживает цель и ограничения, источники делают ответы проверяемыми, а изоляция сессий не мешает остальным участникам группы.
