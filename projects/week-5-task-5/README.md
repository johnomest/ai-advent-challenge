# День 25 — CLI-чат с RAG и памятью задачи

Цель: продолжать диалог, не терять цель, уточнения и ограничения; на каждый
новый вопрос искать документы и показывать проверенные источники и цитаты.
Переиспользованы индекс Дня 21, поиск Дня 23 и валидатор Дня 24. Новых зависимостей нет.

## Запуск

Из корня репозитория, `.venv` активировано, Ollama с embeddinggemma работает:

```powershell
python projects/week-5-task-5/main.py
```

Ключ DeepSeek читается из корневого `.env`. В облако отправляются вопрос,
последние шесть ходов, память задачи и выбранные фрагменты PDF.
История локальная, `data/` исключена из Git. Не вводите секреты в чат.

Память фиксируется явно, чтобы модель не выдумывала цели и предпочтения:

```text
/goal Подготовить заявку в Framestore для работы за рубежом
/studio Framestore
/constraint Коротко, сохраняй условия и исключения
/note Я планирую работать за рубежом
/term demo reel = демонстрационный ролик
Нужен ли им диплом?
А что с визой в моей ситуации?
/state
/history
/exit
```

`/goal` и `/studio` заменяют значение; `/constraint`, `/term`, `/note` добавляют
уникальную запись. Обычные сообщения сохраняются в истории, но автоматически
в долгосрочную память не превращаются. Явные уточнения закрепляйте через `/note`.
Каждая команда также сохраняется в истории. `/state` показывает память,
`/history` полную историю. Повторный запуск продолжает ту же сессию.
Для нового диалога укажите новый путь:

```powershell
python projects/week-5-task-5/main.py --session projects/week-5-task-5/data/another-chat.json
```

## Как устроено

LLM разрешает «они», «а образование?» по памяти и последним сообщениям →
локальный поиск по исходному и самостоятельному запросам → порог и реранкинг →
ответ Дня 24 с точными цитатами. История и память не считаются доказательствами
политик студий; источники берутся только из найденного индекса.
На каждый вопрос выводятся `SEARCH`, `FILTERING`, `ANSWER`, `SOURCES`, `QUOTES`.
При отказе источников нет — это явно указано. Команда памяти не вызывает RAG,
не является документальным ответом и не получает выдуманные ссылки.

Состояние записывается атомарно после успешного хода; ошибка API или записи
не изменяет сессию в памяти. Исходный вопрос можно повторить. Полная история
остаётся на диске, в промпт попадают последние шесть ходов и память задачи.
Одна сессия рассчитана на один CLI-процесс: конкурентный запуск с одним файлом
не поддерживается. JSON содержит личный диалог — не публикуйте его целиком.
Это production-like учебный CLI, не многопользовательский production-сервис.

## Два длинных сценария

`scenarios.json`: Framestore и IV, каждый по 12 пользовательских сообщений:
пять команд памяти и семь RAG-вопросов, включая местоимения и возврат к цели.
Между каждым сообщением файл реально перечитывается, проверяя сохранение памяти.

```powershell
python projects/week-5-task-5/main.py --scenario framestore --session projects/week-5-task-5/data/framestore-video.json
python projects/week-5-task-5/main.py --scenario iv --session projects/week-5-task-5/data/iv-video.json
```

Нужны новые пути: сценарий не перезаписывает существующую историю.
Обычный вопрос — два облачных вызова: разрешение контекста и ответ; возможна одна
повторная генерация при невалидной цитате. Поиск и embeddings локальные.
`goal_retained` проверяет сохранение поля цели, не смысл ответа. Самостоятельный
поисковый запрос, выбранную студию и ответ проверяем отдельно вручную.

```powershell
python -m unittest discover projects/week-5-task-5 -v
```

Проверяются возобновление сессии, замена студии без потери цели, дедупликация
уточнений, ограничение контекстного окна и сохранность истории при сбое API.
Ограничения перевода, релевантности и семантической поддержки из Дня 24 остаются.
