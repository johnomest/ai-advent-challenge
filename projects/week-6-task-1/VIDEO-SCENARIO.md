# День 26 — сценарий видео

Имя: `usage-video-w6-t1.mp4`.

1. Показать установленную модель:

```powershell
ollama list
```

2. Показать доступность локального HTTP API:

```powershell
Invoke-RestMethod http://127.0.0.1:11434/api/version
```

3. Запустить три запроса:

```powershell
python projects/week-6-task-1/main.py
```

Показать все три `QUESTION` / `ANSWER`, метрики и `Saved`.
Объяснить увеличение сложности: факт → JSON с точными данными → оптимизация.
Сравнить третий ответ с эталоном A+B, 8 часов, 210. Ошибку модели не скрывать.
В проверенном прогоне модель выбрала A+C и получила 200; поэтому `CHECKS: 2/3`.
Новый прогон может отличаться, показываем фактический результат.

4. Показать локальную загрузку и GPU:

```powershell
ollama ps
```

Проверить `PROCESSOR` и `CONTEXT`. Нельзя выводить «100% GPU» из одной скорости
генерации: это отдельно подтверждает `ollama ps`.

5. При желании продемонстрировать CLI Ollama:

```powershell
ollama run gemma4:12b-it-qat
```

```text
/set parameter num_ctx 8192
Привет! Представься одним предложением на русском.
/bye
```

Итог: модель запущена локально и отвечает через HTTP/CLI. Около 50 токенов/с
на этих коротких ответах после загрузки; скорость зависит от запроса и нагрузки.
