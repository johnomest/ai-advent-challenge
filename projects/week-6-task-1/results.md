# День 26 — реальный локальный прогон

Дата: 2026-10-05. Установленная модель `gemma4:12b-it-qat`, digest
`38044be4f923e5a55264ed7df4eaac2676651a905f735197c504045140c02bd3`.
Ollama HTTP API: `http://127.0.0.1:11434`. Контекст 8192, temperature 0,
thinking отключён, максимум 768 выходных токенов. Облачных запросов нет.

## Запуск и размещение

`/api/tags` подтвердил наличие модели, `/api/chat` вернул три завершённых ответа.
`ollama ps` показал **100% GPU**, контекст **8192**. `/api/ps` подтвердил
`size == size_vram == 7661735115` байт для загруженной модели.
Размер установленного файла модели: 7151003754 байт; это не тот же показатель,
что runtime footprint с контекстом.

## Три запроса

1. **Простой:** столица Франции. Ответ «Париж», проверка пройдена.
   4 выходных токена, 43.01 токена/с; полное время 6.160 с, из них загрузка 5.909 с.
2. **Структурированный:** JSON с артистом, датой и бюджетом.
   Astin Ray, 2026-10-12 и 108000 сохранены точно; формат JSON валиден.
   47 токенов, 51.42 токена/с, полное время 1.014 с, загрузка 0.003 с.
3. **Аналитический:** выбор проектов с максимальной прибылью при лимите 8 часов.
   Модель выбрала A+C: 7 часов, прибыль 200, и ошибочно назвала этот выбор
   оптимальным. Правильный выбор A+B: 8 часов, прибыль 210. Кроме того, JSON
   обёрнут в Markdown вопреки инструкции «только JSON».
   92 токена, 49.36 токена/с, полное время 1.983 с, загрузка 0.003 с.

Все три ответа закончились `done_reason=stop`, обрывов не было.
Контроль качества: **2/3**, запуск/получение ответов: **3/3**.
Код завершился с 1 из-за контрольной ошибки, не из-за сбоя сервера.

Вывод: задача локального запуска выполнена. Модель сохраняет точные данные
в проверенном структурированном запросе, но может ошибаться в оптимизации
и нарушать формат. Температура 0 не делает ответ гарантированно правильным.
Показатели скорости относятся к этому короткому прогону, не к универсальному benchmark.

Полные запросы, ответы, метрики и состояние GPU сохранены в `data/results.json`
(исключено из Git). Три unit-теста проходят, новых зависимостей нет.
