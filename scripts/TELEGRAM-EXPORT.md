# Выгрузка Telegram без бота

Скрипт читает один выбранный существующий чат от вашего аккаунта. Не отправляет
сообщения, не вступает в группы, не отмечает историю прочитанной. После входа
проверяет точное название/ID среди доступных групп и каналов и просит подтверждение.

## Первый запуск

1. Откройте https://my.telegram.org → API development tools. Создайте приложение,
   получите `api_id` и `api_hash`. Не используйте чужие ключи.
2. В терминале из корня репозитория:

```powershell
.venv/Scripts/python.exe -m pip install -r scripts/requirements-telegram.txt
.venv/Scripts/python.exe scripts/export_telegram.py --chat "ТОЧНОЕ НАЗВАНИЕ ГРУППЫ"
```

3. Введите API ID, API hash, номер телефона, код Telegram и пароль 2FA (если включён).
   Код, API hash и пароль вводятся скрыто. Ничего из этого не отправляйте в чат Codex.
4. Проверьте выбранную группу и введите `YES`.

API credentials можно также передать через переменные окружения `TELEGRAM_API_ID`
и `TELEGRAM_API_HASH`. Скрипт не читает и не изменяет существующий `.env`.

## Результат и повторный запуск

`chat/telegram/<chat_id>/result.json`: текст, ID, UTC-даты, автор-ID, ответ на
сообщение, признак вложения. Вложения не скачиваются; имена авторов не выгружаются.
Это собственный формат с массивом `messages`, не точная копия Telegram Desktop JSON.

Повторный запуск полностью перечитывает доступную историю и атомарно заменяет
файл: учитывает отредактированные и удалённые сообщения. При сбое старая выгрузка
сохраняется. История собирается постранично, поэтому изменения во время выгрузки
могут потребовать повторного запуска. Скрытая/удалённая до выгрузки история
недоступна. Нет расписания, инкрементальной синхронизации или загрузки в LLM.

## Безопасность

Сессия: `.local-archive/telegram/reader.session`. Сессия и `chat/` исключены из Git.
Сессия даёт полноценный доступ к аккаунту: Telegram не предоставляет для неё
read-only права. Только наш скрипт ограничен чтением. Не копируйте сессию в облако
или на общий диск. Защищайте Windows-аккаунт; отозвать доступ можно через
Telegram → Настройки → Устройства.

Документация:
- https://core.telegram.org/api/obtaining_api_id
- https://docs.telethon.dev/en/stable/concepts/sessions.html

Проверка без Telegram:

```powershell
.venv/Scripts/python.exe -m unittest discover -s scripts -p test_export_telegram.py
```
