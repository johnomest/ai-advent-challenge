# Pitch Agent: локальный сайт

Дата: 2026-09-07  
Статус: Done

## Задача

Добавить простой сайт к музыкальному PitchAgent для локальной работы пользователя и демонстрации куратору. Нужны полноценный диалог с моделью, понятный интерфейс и обычный человеческий тон.

## Research

Выбран Python-сервер из стандартной библиотеки и vanilla HTML/CSS/JavaScript. Новые зависимости и сборщик не нужны. Поток запроса: браузер → локальный HTTP API → PitchAgent → DeepSeek. API-ключ остаётся на сервере.

Границы безопасности: привязка к 127.0.0.1, отдельные браузерные сессии с HttpOnly-cookie, проверки Host/Origin, ограничение тела запроса и разрешённый список статических файлов. История хранится в памяти сервера.

UI-концепция Hallmark: Split Studio, сдержанная композиция с коралловым акцентом, адаптивная раскладка и доступное управление с клавиатуры.

## Plan

1. Сделать обновление истории и статистики PitchAgent атомарным: сначала проверить ответ провайдера, затем сохранить результат.
2. Добавить локальный сервер и API: GET /api/session, POST /api/messages, DELETE /api/session.
3. Реализовать форму трека, диалог, статистику, копирование ответа, подтверждение сброса и восстановление после ошибок.
4. Добавить проверки агента и HTTP API, документировать запуск.
5. Проверить Backend и Web, включая реальный вызов DeepSeek и сценарии ошибок.

## Реализация

Файлы в `projects/week-2-task-1/`:

- `main.py` — PitchAgent, история диалога, статистика токенов и проверка ответа провайдера до изменения состояния.
- `web.py` — сервер, API, браузерные сессии, выдача статических файлов и проверки входящих запросов.
- `static/index.html` — форма, диалог, статистика, подтверждение сброса, inline SVG favicon.
- `static/tokens.css`, `static/styles.css` — визуальные токены, адаптивная раскладка, состояния полей и кнопок, фокус.
- `static/app.js` — отправка сообщений, восстановление сессии, копирование, сброс, обработка ошибок. Ответы выводятся через textContent.
- `test_main.py`, `test_web.py` — проверки агента, истории, токенов, ошибок, сессий и HTTP-границ.
- `README.md` — запуск сайта и CLI, настройки, ограничения сессий и команды проверок.
- `.hallmark/preflight.json`, `.hallmark/log.json` — решения дизайна и результаты проверок Hallmark.

Диалог сохраняется при обновлении страницы. Повторная отправка блокируется на время запроса. При ошибке сохраняются черновик и предыдущая история. После потери связи интерфейс проверяет состояние диалога перед повторной отправкой.

## Условия эксплуатации

Запуск: `python projects/week-2-task-1/web.py`, адрес: http://127.0.0.1:8000. Нужен DEEPSEEK_API_KEY в существующей конфигурации `.env`.

Сайт предназначен для локальной работы. История исчезает после перезапуска сервера или двух часов бездействия; вкладки одного профиля разделяют сессию. Сообщения отправляются облачному DeepSeek API. Публикация, Asana, Telegram и GitHub push в эту стадию не входят.
